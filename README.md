# Cosmion

jogo de perguntas com tema espacial, inspirado no krillion. tem que responder algo valido mas o mais raro possivel, quanto mais rara a resposta mais longe a nave vai.

sao 7 perguntas por viagem, 20 segundos cada.

pra jogar é so abrir o index.html no navegador ou entrar em https://stardust-sandy.vercel.app
